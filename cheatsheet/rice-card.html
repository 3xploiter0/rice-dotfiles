Start a hack

htb <ip> <box>Sets the target, builds ~/htb-machines/<box>/ with nmap/ loot/ exploits/ notes.md, and opens a tmux workspace: nmap on the target, an rlwrap nc listener on 4444, notes in nvim, plus a free shell window.
tmux attach -t <box>Re-open that workspace later (or just run htb again)
recon <ip>Full port scan, then auto-enum each service (web dirs, SMB, FTP…) into the box folder. No ip = current target.
addhost <ip> <name>Add /etc/hosts entry · addhost <name> = remove
