# Cybersecurity learning roadmap

Mark done with [x]. Edit freely: `roadmap` (opens this), add your own.

## 0 · Foundations
- [ ] Linux CLI fluency (pipes, find, grep, permissions, cron)
- [ ] Networking: TCP/IP, ports, DNS, HTTP, subnetting
- [ ] Bash + a scripting language (Python)

## 1 · Recon & scanning
- [ ] nmap deep-dive (scripts, timing, output formats)
- [ ] Web enum: ffuf/feroxbuster, vhosts, wordlists
- [ ] Service enum: SMB, FTP, SNMP, LDAP

## 2 · Web exploitation
- [ ] OWASP Top 10 hands-on (PortSwigger Web Security Academy)
- [ ] SQLi, XSS, SSRF, LFI/RFI, file upload, auth bypass
- [ ] Burp Suite workflow (proxy, repeater, intruder)

## 3 · Foothold & shells
- [ ] Reverse/bind shells, TTY upgrade, pivoting (chisel/ligolo)
- [ ] Password attacks: hashcat/john, hydra, spraying

## 4 · Privilege escalation
- [ ] Linux privesc (linpeas, SUID, sudo, cron, capabilities)
- [ ] Windows privesc (winpeas, tokens, services, UAC)

## 5 · Active Directory
- [ ] AD basics, BloodHound, Kerberoasting, AS-REP, DCSync
- [ ] Lateral movement, pass-the-hash

## 6 · Practice & proof
- [ ] 20+ HTB/THM boxes (track with `boxes`)
- [ ] Write 5 writeups (`writeup <box>`)
- [ ] A cert goal (eJPT / PNPT / OSCP)

## Daily habit
- [ ] 1 box or 1 PortSwigger lab
- [ ] `journal` what you learned
- [ ] `brief` to stay current
